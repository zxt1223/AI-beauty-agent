## 四、横切口径与坑（口径必读）

1. **首答分母随「可答集」变化**：94.7%（分母 19 锚点）、78.9%（早期 19→15 时代）、26.7%（v3 分母 75）——**引任何首答数字必须带评测集与分母**。
2. **锚点 vs v3 两套评测域**：锚点 = 24 人工精心标 gold（高命中是应该的）；v3 = 真实评论压力测试（26.7% 是诚实基线）。混着说必被反问。
3. **两个「置信度」不是一回事**：①llm_gate 三档闸门（>85 直出/60-85 复核/<60 转人工）——**规则预分类固定分 + LLM 自评，未统计校准，85/60 是工程定标**；②reranker 语义试探 conf——θ=0.05 同样工程定标。说「置信度」必须指明是哪一层。
4. **信任信号 = 检索兑现率（非 LLM 自报置信度）**：意图→规范轴→库内 ≥20→top-8 兑现 ≥0.5 才采信，任一不过降级回规则。
5. **避雷共识口径（2026-09-02 P0-1 后）**：分母 = 该商品**负面评论总数**（`n_neg_reviews`），非含好评全部评论；该商品负面 ≥5 条（`DEFECT_MIN_NEG`）才参与判定，且缺陷轴提及 ÷ 负面 ≥70%（`DEFECT_CONSENSUS`）才硬避雷。旧口径归档 `legacy_consensus_axes()`。
6. **评测集规模口径**：eval_review_50 = **200 行**（41 锚点 v2 + 159 v3 ids 42-200）；对比表1 仍是 41（v3 未进）；`data/eval_review_50.csv`（11 行）是 **v1 遗留样例，不是 200 行快照**。
7. **候选池规模口径**：candidate_pool_v2 = **10702 行 / 200 题**（2026-09-02 v3 扩池重建）；早期文档「2249/41 题」已过时。
8. **标签覆盖口径**：遮瑕 coverage_tag 395/1090 = **36.2%**（field 18 + title 73 + 人工 14），未标 695 靠 Agent 诚实兜底——「未标 ≠ 不适用」。
