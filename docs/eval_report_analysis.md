## 6. 核心结论

- **规则能覆盖的题（锚点 19 道）**：15/19 = 78.9% 首答命中，CONTRACT 105/105——规则主干扎实

- **规则的漏（hidden 9 道盲区题）**：纯规则 0/9 全懵，规则+LLM 兜底 7/9——LLM 价值 = 规则的漏，信任信号 = 检索兑现率而非自报置信度

- **排序选型**：tagfirst 优于 mixed（首答 78.9% vs 对照），结构化标签是主干，向量仅小权重辅助

- **坏例闭环**：失败层集中在检索排序不足，已登记 + 归因 + 修复动作，可回归
