## 1. 段 B 目标

1. 兑现段 A badcase 对策：q9 坎昆防水（MRR 0.125）、q1 高遮瑕（NDCG 0.152）
2. 四模式消融（bm25 / tag / vec / mixed）+ mixed 权重**正式定参**（段 A 的 α/β/γ 是拍的，段 B 用网格扫描）
3. 模型离线化（检索服务可部署在无外网环境）

## 2. 最终四模式消融表（候选池内，11 query）

| 模式 | NDCG@5 | Recall@5 | MRR | 避雷准确率 |
|---|---|---|---|---|
| bm25 | 0.014 | 0.019 | 0.108 | 0.815 |
| **tag** | **0.652** | **0.694** | **0.818** | 0.741 |
| vec | 0.115 | 0.111 | 0.260 | 0.889 |
| **mixed（定参）** | **0.457** | **0.606** | 0.594 | **0.926** |

`mixed = 0.3·BM25 + 1.5·标签 + 0.1·向量 + 0.3·热度`（min-max 归一化后加权 + 动态路由偏置 + 置信度降权）

**段 A mixed 0.445 → 段 B 0.457（NDCG +0.012）；Recall@5 0.495 → 0.606（+0.111）；避雷准确率 0.926 持平。**

## 3. 三个迭代发现（诚实过程）

### 发现 1：向量独立区分度弱——「embedding 一把梭」的实证反证
首版商品文档只 `title+brand`，vec 单独只有 **0.082**。诊断：
- 相似度全部挤在 **0.5–0.7 窄带**，gold−候选均值差 ≈ 0（q1 **−0.017**、q4 −0.054、q5 −0.000）
- gold 平均排名 15–45 位（越接近 1 越好）

**真实长句 query 与 Amazon 营销 title 的语义鸿沟，通用句向量跨不过。** 结构化标签分（tag 0.652）才是真正的主力——这直接反驳了「加个 embedding 就解决检索」。

### 发现 2：结构化↔向量对齐，向量才吃到标签维度（0.077→0.115）
两处修改，都是**索引/引擎层**，不碰 v13 金标准口径：
- 商品文档 = title + brand + **英文原始标签列**（finish_type / coverage / item_form / skin_type / skin_tone）
- query 向量 = query_rewrite + **结构化字段英译注词**（build_vec_query：高遮瑕→full coverage、哑光→matte finish、干皮→dry skin…）

向量从「纯语义」变为「语义 + 标签对齐」。收益：q5 hard 约束 MRR 0.167→**1.000**、q6 0.585→0.742、q8 0.434→0.612。

### 发现 3：δ=0.1 小权重辅助最优（grid_scan 定参）
固定 α=0.3 / β=1.5 / γ=0.3，扫向量权重 δ：

| δ | NDCG@5 | Recall@5 | MRR | 避雷准确率 |
|---|---|---|---|---|
| 0.0 | 0.445 | 0.495 | 0.678 | 0.926 | ← 与段 A 完全一致（校验扫描正确） |
| **0.1** | **0.457** | **0.606** | 0.594 | 0.926 | ← **最优** |
| 0.3 | 0.421 | 0.569 | 0.538 | 0.926 |
| 0.5 | 0.409 | 0.569 | 0.511 | 0.889 |
| 1.0 | 0.373 | 0.551 | 0.479 | 0.926 |
| 2.0 | 0.297 | 0.389 | 0.437 | 0.926 |

**结论：向量单独很弱，但小权重下大幅捞 Recall（+0.111）、NDCG 微升、避雷不损；δ 调大向量噪声污染混合（2.0 → 0.297 崩溃）。** embedding 在检索里的正确角色是「语义辅助兜底」，不是主干。

## 4. Badcase 兑现情况

| query | 段 A | 段 B | 结论 |
|---|---|---|---|
| q9 坎昆防水防晒 | MRR 0.125 / Recall 0 / NDCG 0 | MRR 0.200 / Recall **1.000** / NDCG **0.387** | **gold 全进 top5，向量语义兜底兑现** |
| q1 高遮瑕·斑驳肌 | NDCG 0.152 / MRR 0.143 | NDCG 0.152 / MRR **0.333** | MRR 提升、primary 进 top5；难例同质化（15 个全 high coverage）边界仍在 |
| q7 轻质控油粉饼 | NDCG 0.303 | NDCG 0.191 / MRR **0.500** | MRR 提升；NDCG 受难例干扰 |

**q9 兑现机制**：query_rewrite 注词（waterproof / SPF / sun protection）+ 商品文档含 SPF title + 结构化英译注词 → 向量把 SPF/防水类商品拉进 top5。隐式意图（去海边→防晒防水）由「规则注词 → 向量对齐」间接解决——**不是模型推理，是结构化信号注入**。这支撑 Phase 2 的改写/追问决策节点：隐式意图靠规则 + 注入，不靠模型瞎猜。

## 5. 工程可部署性

- **模型离线化**：`download_bge.py` 经本地代理拉取模型全文件（10 文件 134MB）到 `models/`，`enable_vectors` 优先本地路径加载，**无在线依赖**，可部署到无外网环境
- 在线加载失败实证：hf-mirror 对 resolve/ 返回 308→huggingface.co（国外），transformers 直连 OSError → 改代理 + 离线方案，诊断链完整
- **性能**：query 向量单次编码缓存 + 矩阵乘法（避免每候选重复 encode，千次→几十次）

## 6. 阶段口径（段 B）

> 「我装上 bge embedding 跑四模式消融，第一个发现是向量独立区分度很弱（NDCG 0.115）——真实长句 query 和 Amazon 营销 title 的语义鸿沟，通用句向量跨不过，相似度全挤在 0.5–0.7 窄带。这是对『加个 embedding 就解决检索』的直接反驳。第二个发现是让商品文档和 query 都带结构化标签的英文词后，向量才吃到标签维度（0.077→0.115），q5 硬约束 MRR 直接 1.0。第三个发现是权重网格扫描里 δ=0.1 最优：向量作为小权重语义辅助，Recall 从 0.495 提到 0.606、NDCG 微升、避雷准确率 0.926 一点不损；δ 调大反而把混合拉到 0.297。所以我的检索不是 embedding 一把梭，是结构化标签做主干、向量做语义兜底。」
